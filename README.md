## <a name="tr-türkçe"></a>🇹🇷 TR - Türkçe

### Hakkında
Bu proje, kullanıcıların sayı değerlerini artırıp azaltabileceği, başlangıç değeri belirleyebileceği ve temayı değiştirebileceği interaktif bir **Sayaç (Counter)** uygulamasıdır. Uygulama **React** kullanılarak geliştirilmiştir ve kullanıcı verileri **LocalStorage** üzerinde kalıcı olarak saklanır. Bu sayede sayfa yenilense veya tarayıcı kapatılsa bile sayaç ve tema ayarları kaybolmaz.

### 🚀 Özellikler
- ✅ **Artırma ve Azaltma:** Sayaç değerini butonlarla dinamik olarak değiştirme.
- 🧮 **Başlangıç Değeri Belirleme:** Kullanıcı, istediği başlangıç değerini girip sayacı o değerden başlatabilir.
- 🔁 **Sıfırlama:** Sayaç değerini tek tıkla sıfırlama.
- 💾 **Kalıcı Veri Saklama:** Sayaç ve tema bilgileri tarayıcı **LocalStorage**'ında saklanır.
- 🌓 **Tema Değiştirme (Açık/Koyu Mod):** Kullanıcılar açık ve koyu tema arasında geçiş yapabilir.
- 🎨 **Modern Arayüz:** Responsive ve sade tasarım.
- ⚡ **Otomatik Geri Yükleme:** Sayfa yenilendiğinde en son kullanılan değerler otomatik yüklenir.

### 🧩 Kullanılan Teknolojiler
| Teknoloji | Rolü |
|------------|-----------|
| **React (CRA)** | Uygulamanın temel yapısı. |
| **JavaScript (ES6+)** | Mantıksal işlemler ve LocalStorage. |
| **CSS3** | Modern ve responsive arayüz tasarımı. |
| **LocalStorage API** | Verilerin kalıcı saklanması. |

## <a name="eng-english"></a>🇺🇸 ENG - English

### About
This project is an interactive **Counter** application where users can increment or decrement values, set a custom starting point, and switch themes. Built with **React**, it uses **LocalStorage** to persist user data, ensuring settings remain even after a page refresh or browser restart.

### 🚀 Features
- ✅ **Increment & Decrement:** Change the counter value dynamically using buttons.
- 🧮 **Custom Start Value:** Start the counter from any number you choose.
- 🔁 **Reset:** Reset the value with a single click.
- 💾 **Persistent Data:** Data is saved in the browser's LocalStorage.
- 🌓 **Theme Switcher (Light/Dark):** Toggle between Light and Dark modes.
- 🎨 **Modern UI:** Responsive and clean design.
- ⚡ **Auto-restore:** Last used values are automatically restored on page reload.

### 🧩 Technologies Used
| Technology | Role |
|------------|-----------|
| **React (CRA)** | Core application structure. |
| **JavaScript (ES6+)** | Logic and LocalStorage functions. |
| **CSS3** | Modern and responsive UI design. |
| **LocalStorage API** | Persistent data storage. |

## <a name="de-deutsch"></a>🇩🇪 DE - Deutsch

### Über das Projekt
Dieses Projekt ist eine interaktive **Zähler-App (Counter)**, mit der Benutzer Werte erhöhen oder verringern, einen Startwert festlegen und das Design ändern können. Die Anwendung wurde mit **React** entwickelt und speichert Benutzerdaten dauerhaft im **LocalStorage**, sodass Einstellungen auch nach einem Neustart erhalten bleiben.

### 🚀 Funktionen
- ✅ **Erhöhen & Verringern:** Dynamische Änderung des Zählerwerts über Schaltflächen.
- 🧮 **Startwert Festlegen:** Den Zähler bei einem beliebigen Wert starten.
- 🔁 **Zurücksetzen:** Den Zählerwert mit einem Klick zurücksetzen.
- 💾 **Dauerhafte Speicherung:** Daten werden im LocalStorage des Browsers gespeichert.
- 🌓 **Themenumschaltung (Hell/Dunkel):** Wechsel zwischen Hell- und Dunkelmodus.
- 🎨 **Modernes Design:** Responsive und benutzerfreundliche Oberfläche.
- ⚡ **Autom. Wiederherstellung:** Werte werden beim Neuladen automatisch geladen.

### 🧩 Verwendete Technologien
| Technologie | Rolle |
|------------|-----------|
| **React (CRA)** | Grundstruktur der Anwendung. |
| **JavaScript (ES6+)** | Logik und LocalStorage-Funktionen. |
| **CSS3** | Modernes und responsives Design. |
| **LocalStorage API** | Dauerhafte Datenspeicherung. |
